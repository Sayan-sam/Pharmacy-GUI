# Releases

This folder contains the release builds of the Pharmacy Management System.

## Latest Release

Download the latest version from the [GitHub Releases](https://github.com/yourusername/Pharmacy-GUI/releases) page.

## Running the Application

### Windows
1. Download `Pharmacy-Management-System-x.x.x.jar`
2. Download `run.bat`
3. Double-click `run.bat` to launch

### Linux/Mac
1. Download `Pharmacy-Management-System-x.x.x.jar`
2. Download `run.sh`
3. Make it executable: `chmod +x run.sh`
4. Run: `./run.sh`

### Manual Execution
```bash
java -jar Pharmacy-Management-System-x.x.x.jar
```

## System Requirements
- Java Runtime Environment (JRE) 8 or higher
- 512 MB RAM minimum
- 100 MB disk space
